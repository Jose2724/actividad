**Parar y reanudar una línea**
1. **⏸ Parar** en la tarjeta de la línea.
2. Escoger la razón:
   - Con **reason codes prendidos** (Ajustes › Paros): primero la **categoría** (los cuadros de colores) y después el **código**. El detalle es opcional, salvo en **OTH-01 Otro**, que pide explicarlo.
   - Con reason codes apagados: las razones rápidas del cuarto (Problema mecánico, Break, Lunch…) u **Otra** (escribir la razón).
   - Si las reglas de paros del turno están prendidas: en **Problema mecánico** se escribe el **nombre del mecánico**; y en vez de "Otra" sale **🙋 Avisar al manager** (el paro cuenta desde ya y el manager escribe la razón).
3. **⏸ Confirmar paro**. La tarjeta se pone roja y cuenta el tiempo parado.
4. Cuando vuelven a trabajar: **▶ Reanudar**.
- Si se para **todo el cuarto** (break, lunch, falta de producto…): **⏸ Parar departamento** arriba del cuarto. Las líneas dicen "Parado por el departamento".
- El tiempo **Parado** solo cuenta mientras la línea tenía un código.
- Managers: arriba del cuarto salen los **Paros que esperan tu razón** (los de "Avisar al manager"): **Arreglar** para escribirla.

**Set up (cambio de producto)**
- **⏱ Set up** en una línea libre, o al terminar un código cuando viene otro. Al terminar de preparar: **✓ Set up listo** (o se termina solo cuando empieza el siguiente código).
- El Set up **no cuenta como parado**: sale en amarillo y en el reporte va aparte.
- Un Set up **nunca cuenta con nadie trabajando**: espera al siguiente código; si se queda abierto mucho tiempo sin código, el servidor lo termina o lo quita.
- Con reason codes, el Set up es **PLN-03 Cambio de producto (Set up)**.
- Managers y oficina: **⏱ Set up en todas las líneas** pone todas las líneas libres en Set up de un toque (al empezar el turno).

**Cómo escoger el reason code correcto**
- Pregúntate qué paró la línea de verdad: ¿estaba planeado (break, limpieza, junta)? ¿falló una máquina? ¿faltó material o gente? ¿calidad? ¿iba lento?
- **Planeado** (PLN-…) es lo que se sabía de antemano. Lo demás es no planeado.
- Cada código cae en una familia OEE: **Disponibilidad** (la línea no pudo correr), **Rendimiento** (corría pero más lento o con micro-paros), **Calidad** (producto que no cumple, retrabajo, inspección).
- Si nada aplica: **OTH-01** y explicar en el detalle.
