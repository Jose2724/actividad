- Se cuenta por **bin** (o bag). Lo que dice cada bin se cuenta tal como se escribe: no se convierte a cajas.
- Al empezar: código, lote y **¿En qué se llena y qué lleva?**
  - **Platos** o **Copas**: cada bin dice cuántos.
  - **Libras**: cada bin se pesa.
  - **Bags**: bags de libras para el **roaster**; cada bag se pesa.
  - **Pouches en carros** (como RTE: carro listo) o **Pouches en bin** (cuando MFO ayuda a RTE).
- Cada bin: **✓ Bin listo** (o **✓ Bag lista**) y escribir cuántos platos, copas, pouches o libras lleva. El **N° de bin** es opcional.
- La próxima vez que empiecen un código en esa línea ya sale escogido lo mismo.
- Si el roaster ya corre como "bin": terminen el código y empiécenlo otra vez escogiendo **Bags**.
- Razones rápidas de paro (si los reason codes están apagados): Problema mecánico, Falta de producto del freezer, Break, Lunch, Otra.
