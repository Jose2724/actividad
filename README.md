# Actividad (demo)

Demo para registrar la actividad de producción por departamento (Kitchen, RTE, Spiral, MFO, Packing):
líneas por departamento, código y lote que corre cada línea, tiempo trabajando, carros terminados,
paros con su razón y tiempo parado, y un reporte del día exportable (CSV para Excel / imprimir).

- Es un demo: los datos se guardan solo en el dispositivo (tablet o teléfono). La versión completa
  sincroniza con un servidor para que el manager lo vea en vivo y exporta a Excel, PDF y Google Sheets.
- Hecho por José E. García con React + TypeScript + Vite. Página publicada desde la carpeta `docs/`.

Desarrollo: `npm install`, `npm run dev`. Publicar: `npm run build` (genera `docs/`) y subir a GitHub.
